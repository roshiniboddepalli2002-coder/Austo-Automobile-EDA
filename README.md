# Austo Automobile – Exploratory Data Analysis

## Project Overview
This project explores customer demographics, financial information, loan preferences and automobile purchase behaviour using Python.

## Dataset
- 1,581 customer records
- 14 variables
- Customer demographics, income, loans and car preferences

## Tools and Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning and inspection
- Univariate analysis
- Multivariate analysis
- Correlation analysis
- Histograms, countplots and boxplots
- Customer behaviour analysis

## Key Findings
- SUV customers have the highest average car price.
- Age has a strong positive correlation with car price.
- Female customers have a higher median car price than male customers.

## Conclusion
The project explores relationships between customer characteristics, financial factors and automobile purchasing behaviour.
